# Block Architecture Studio - Static Site Generator (SSG)

This folder contains Python automation scripts that act as a lightweight, database-free Content Management System (CMS) for your architecture portfolio.

## Architecture
Instead of relying on heavy Python web servers (Django/Flask) or paying for cloud databases, we use an **SSG approach**. All project data is stored locally in `js/data/projects.js` and pages are built dynamically on the client side using static HTML templates. This ensures your website loads instantly, is 100% secure from hacks, and is free to host anywhere (Vercel, Netlify, cPanel).

## How to add a new project
Whenever you design a new building and want to add it to the website, follow these steps:

1. Open your terminal in the main folder (`block-site`).
2. Run the generator script:
   ```bash
   python3 generator-apps/add_project.py
   ```
3. The script will ask you for the Farsi and English details of your project (Title, Area, Description, etc.).
4. The script will automatically:
   - Create `your-project-slug.html` based on `generator-apps/templates/project.html`.
   - Create a folder at `assets/your-project-slug/` for your images.
   - Write all your bilingual text natively into the `js/data/projects.js` database.
5. Finally, drag and drop your renders/images into `assets/your-project-slug/` and update the filenames in `js/data/projects.js` if necessary.

## Templates
- `templates/project.html`: The master HTML shell. The `js/project-template.js` engine reads this file and populates it with the data generated by the python script. Do not delete this file!

## WebP Image Converter (`convert_to_webp.py`)
To duplicate and optimize all photos in a project folder (and all its subfolders) into modern `.webp` format:

```bash
# Basic usage (interactive prompt if path is omitted)
python3 generator-apps/convert_to_webp.py assets/renovation/Ozgol-renovation-project

# Or using relative path / folder name:
python3 generator-apps/convert_to_webp.py Ozgol-renovation-project

# Options:
#   -q, --quality       WebP quality (default: 85)
#   -f, --overwrite     Overwrite existing .webp files
#   -l, --lossless      Use lossless compression (for drawings/diagrams)
#   -d, --delete-original Delete original photo files after conversion
python3 generator-apps/convert_to_webp.py assets/villa/Damas-Villa -q 85 -f
```
