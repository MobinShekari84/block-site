# SEO & Web Vitals Engineering

## 1. Core Principles
- **Sub-Second LCP:** Preload critical project hero images and defer off-screen imagery.
- **Zero CLS:** Strictly typed image dimensions and aspect ratios mapped into CSS and HTML.
- **Semantic HTML5:** Strict adherence to semantic document outlines (`<main>`, `<article>`, `<nav>`, `<figure>`).

## 2. Image Optimization Strategy
Given the visual nature of the architecture studio, image delivery is the most critical performance vector.
1. **Format Enforcement:** All user-uploaded imagery is served in Next-Gen formats (`WebP` or `AVIF`).
2. **Responsive Srcsets:** The platform dynamically injects `sizes` attributes for studio gallery grids to ensure mobile devices do not download 4K desktop assets.
3. **LQIP (Low-Quality Image Placeholders):** During SSR, the `blurHash` from the JSON schema is converted to a base64 inline string and used as a CSS background placeholder while the high-res image loads.
4. **Fetch Priority:** 
   - `fetchpriority="high"` is explicitly applied to the initial LCP hero image.
   - `loading="lazy"` and `fetchpriority="low"` are applied to below-the-fold content.

## 3. Dynamic Metadata & SEO
Every project and category page dynamically resolves its semantic metadata during the SSG build process.

- **Canonical URLs:** Handled dynamically based on the requested slug and current locale.
- **Bilingual SEO (Hreflang):** Every page injects proper `<link rel="alternate" hreflang="fa" />` and `<link rel="alternate" hreflang="en" />` tags, mapping to the bilingual structure.
- **OpenGraph & Twitter Cards:** Dynamic `<meta>` tags are generated using the project's title, description, and `coverImage`.

## 4. JSON-LD Structured Data
To maximize search engine understanding, JSON-LD blocks are injected dynamically based on the route context.

### Global / Homepage
Injects the `ArchitecturalFirm` (or `LocalBusiness`) schema.
```json
{
  "@context": "https://schema.org",
  "@type": "ArchitecturalFirm",
  "name": "Block Architecture Studio",
  "url": "https://blockarch.studio",
  "address": { ... }
}
```

### Project Pages
Injects `VisualArtwork` and `BreadcrumbList`.
```json
{
  "@context": "https://schema.org",
  "@type": "VisualArtwork",
  "name": "Villa Alborz",
  "creator": {
    "@type": "Organization",
    "name": "Block Architecture Studio"
  },
  "artMedium": "Architecture",
  "dateCreated": "2024",
  "image": "https://blockarch.studio/assets/images/villa-alborz-hero.webp"
}
```

## 5. Automated Sitemaps & Robots
- `robots.txt`: Prevents crawling of the `/admin` and `/api` namespaces.
- `sitemap.xml`: Dynamically generated by iterating over `projects.json` and `categories.json`, outputting localized URLs (e.g., `/en/projects/villa-alborz` and `/fa/projects/villa-alborz`).
