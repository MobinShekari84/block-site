# SEO & Web Vitals Engineering

## 1. Core Principles
- **Sub-Second LCP:** Preload critical project hero images and defer off-screen imagery.
- **Zero CLS:** Strictly typed image dimensions and aspect ratios mapped into CSS and HTML.
- **Semantic HTML5:** Strict adherence to semantic document outlines (`<main>`, `<article>`, `<nav>`, `<figure>`).

## 2. Image Optimization Strategy
Given the visual nature of the architecture studio, image delivery is the most critical performance vector.
1. **Format Enforcement:** All imagery in the `assets/` folder should be processed as Next-Gen formats (`WebP` or `AVIF`) before upload.
2. **Fetch Priority:** 
   - `loading="lazy"` is applied to all below-the-fold content generated by the `build_ssg.mjs` compiler.
   - The primary hero images in `index.html` and `project.html` templates should omit lazy loading to guarantee an instant Largest Contentful Paint (LCP).

## 3. Dynamic Metadata & SEO
Every project and category page dynamically resolves its semantic metadata during the `build_ssg.mjs` compilation process.

- **Bilingual SEO (Hreflang):** Every page injects proper `<link rel="alternate" hreflang="fa" />` and `<link rel="alternate" hreflang="en" />` tags, mapping to the bilingual directory structure (`/` vs `/en/`).
- **OpenGraph Cards:** Dynamic `<meta property="og:title">` and `<meta property="og:description">` tags are compiled using the project's title and description data.

## 4. True Static Architecture
Because `build_ssg.mjs` physically writes all HTML nodes into the file before deployment:
- Googlebot and other web crawlers immediately digest the full textual content of the site without needing to execute Javascript.
- Social media scrapers (Twitter, WhatsApp, LinkedIn) can instantly read the OpenGraph tags because they are baked into the raw `.html` payload, ensuring accurate link previews.
